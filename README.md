# API Analyzer

Учебный pet-проект на Python для получения, фильтрации и анализа данных о товарах через REST API.

Проект создан для практики работы с API, генераторами, JSON, обработкой ошибок, `datetime` и другими возможностями Python.

## Возможности

- получение данных из REST API;
- обработка JSON-ответа;
- фильтрация товаров по цене;
- фильтрация товаров по категории;
- фильтрация товаров по количеству на складе;
- комбинирование нескольких фильтров;
- расчёт статистики по найденным товарам:
  - максимальная цена;
  - минимальная цена;
  - средняя цена;
  - количество позиций;
  - общее количество товаров на складе;
- вывод времени создания отчёта;
- сохранение отчёта в JSON-файл;
- загрузка сохранённого отчёта;
- обработка ошибок подключения к API.

## Используемые технологии

- Python
- Requests
- JSON
- Generators
- datetime
- обработка исключений
- REST API
