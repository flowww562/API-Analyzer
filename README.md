\# API Analyzer



Учебный pet-проект на Python для получения, фильтрации и анализа данных о товарах через REST API.



Проект был создан для практики работы с API, генераторами, JSON, обработкой ошибок, `datetime` и другими возможностями Python.



\## Возможности



\- получение данных из REST API;

\- обработка JSON-ответа;

\- фильтрация товаров по цене;

\- фильтрация по категории;

\- фильтрация по количеству товара на складе;

\- комбинирование нескольких фильтров;

\- расчёт статистики по найденным товарам:

&#x20; - максимальная цена;

&#x20; - минимальная цена;

&#x20; - средняя цена;

&#x20; - количество позиций;

&#x20; - общее количество товаров на складе;

\- вывод времени создания отчёта;

\- сохранение отчёта в JSON-файл;

\- загрузка сохранённого отчёта;

\- обработка ошибок подключения к API.



\## Используемые технологии



\- Python

\- Requests

\- JSON

\- Generators

\- datetime

\- обработка исключений

\- REST API

Запуск



Для работы проекта требуется Python и библиотека Requests.



Установить Requests:

pip install requests



После установки можно запустить проект:

python api\_client.py



Примечание



Проект разработан для работы с конкретным учебным REST API и не является универсальным анализатором любых сайтов.



Для работы с другим API может потребоваться изменить обработку структуры получаемого JSON и используемые поля товаров.
