# API Analyzer

Учебный pet-проект на Python для получения, фильтрации и анализа данных о товарах через REST API.

Проект создан для практики работы с API, генераторами, JSON, обработкой ошибок, `datetime` и другими возможностями Python.

## Возможности

- получение данных из REST API;
- обработка JSON-ответа;
- фильтрация товаров по цене;
- фильтрация товаров по категории;
- фильтрация товаров по количеству на складе;
- комбинирование нескольких фильтров;
- расчёт статистики по найденным товарам:
  - максимальная цена;
  - минимальная цена;
  - средняя цена;
  - количество позиций;
  - общее количество товаров на складе;
- вывод времени создания отчёта;
- сохранение отчёта в JSON-файл;
- загрузка сохранённого отчёта;
- обработка ошибок подключения к API.

## Используемые технологии

- Python
- Requests
- JSON
- Generators
- datetime
- обработка исключений
- REST API

# Как работает проект

## Данные проходят несколько этапов обработки:
```text
REST API
   ↓
JSON
   ↓
Получение списка товаров
   ↓
Фильтрация по цене
   ↓
Фильтрация по категории
   ↓
Фильтрация по количеству
   ↓
Расчёт статистики
   ↓
Сохранение отчёта в JSON
```
## Пример результата
```text
Максимальная цена: 19.99
Товар: Eyeshadow Palette with Mirror
Минимальная цена: 8.99
Товар: Red Nail Polish
Количество всех позиций: 5
Количество товаров на складе: 392
Средняя цена: 13.39
Время создания файла: September 28 2026 13:31
```
# Запуск

## Для работы проекта требуется Python и библиотека Requests

## Установить Requests:
```text
pip install requests

python api_client.py
```
